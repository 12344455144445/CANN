## 下次优化的读取顺序

1. 先读[可执行优化方案](CANN_算子优化方案_可执行版.md)，明确当前实现、资源预算、精度约束和已失败路线。
2. 读[候选说明](候选_列尺度复用/README.md)、[完整源码](候选_列尺度复用/kernel.asc)、[精确差异](候选_列尺度复用/source.diff)和[审查记录](候选_列尺度复用/review.json)。
3. 对照[v84 基线源码](baseline/kernel.asc)与[15 点设备实测记录](baseline/hardware_validation.json)。v84 曾通过 15/15，最高单次观察分数 25.01，未复测确认稳定收益。
4. 需要方法细节时，按[来源清单](sources_manifest.json)直接读取 `references/cann-samples/` 中固定版本的官方原文。基础学习流程见[学习指南摘要](CANN_学习指南_优化备忘录.md)。
5. 开始工作前核对[历史交接记录](../Carl%20Memory/CANN_续跑记忆.md)及用户最新指令，保存独立候选与逐点比较结果。

## 已落实的优化

通用 Vector 路径在 `N<=3072` 时，第一遍加载的只读列尺度保留在原队列中，第二遍量化直接复用。命中门控时，每次函数调用减少 `4*N` 字节 GM 读取，不新增 UB 缓冲，不改变数值运算顺序。前提是输入尺度只读且不与输出存储重叠。

**候选已经完成结构及缓冲所有权检查，尚未 CANN 编译、NPU 正确性或性能验证。它是可直接输入现有赛题工程的完整源码，尚不能作为已提速推荐版。** 本包没有完整 CANN 工具链和 Host 工程，需要沿用赛题原有构建环境。

下一项独立实验为 Scalar 预取窗口 `64→16`，具体约束见可执行方案第 4 节。后续 VF 融合、完整行驻留、Cube 输入复用与尾轮调度都有前置条件，不与首个候选混做一次实验。
